NIST CAVP HMAC_DRBG Test Vectors for SHA-256

Source: https://csrc.nist.gov/CSRC/media/projects/cryptographic-algorithm-validation-program/documents/drbg/drbgtestvectors.zip
File: drbgvectors_pr_false.zip / HMAC_DRBG.txt (No Prediction Resistance)

These vectors cover:
- SHA-256 hash function
- All combinations of:
  * PersonalizationString (present or absent)
  * AdditionalInput (present or absent)
- No prediction resistance (PR = False)

The subset includes 90 test cases covering all combinations.
