# Brief M1-T2 — physical memory manager from the Limine memory map

## Goal
The kernel knows every byte of RAM, hands out 4 KiB physical frames safely, and can reclaim them.
Everything later (heap, page tables, DMA rings) depends on this being correct and tested.

## Applies
DECISIONS D2 (write the allocator yourself; `spin` is allowed for the lock), D3 (Limine HHDM +
memory map), D5.

## Where things are
Shared modules in kernel/src/lib.rs; tests are `#[test_case]`s in kernel/src/test_main.rs (or a
new kernel/src/tests/ module tree if test_main.rs is nearing 600 lines). Limine requests already
exist for framebuffer/HHDM/memmap in the M0 code (`git grep -n Request kernel/src`). New code goes
under kernel/src/mm/: mod.rs, addr.rs, hhdm.rs, pmm.rs, bitmap.rs.

## Design
1. `mm::addr`: `#[repr(transparent)] PhysAddr(u64)` and `VirtAddr(u64)` newtypes with `as_u64`,
   `align_down/align_up(align)`, `is_aligned`, `frame_index()`; `const FRAME_SIZE: usize = 4096`.
2. `mm::hhdm`: store the Limine HHDM offset once at boot; `phys_to_virt(PhysAddr) -> VirtAddr`,
   `virt_to_phys_hhdm(VirtAddr) -> PhysAddr` (only for HHDM addresses, debug-assert the range).
3. `mm::bitmap`: a `FrameBitmap` over an arbitrary `&'static mut [u64]` covering frames
   `[base_frame, base_frame + count)`: `set_used/set_free/is_used`, `find_free_run(n, align_frames)`
   using word-at-a-time scanning, `count_free()`. Pure logic, no globals, so it is unit-testable
   over a small stack/static array in the test binary.
4. `mm::pmm`: on init, iterate the Limine memory map; log one line per entry
   (`[pmm] 0x<base>-0x<end> <type>`), and a summary. Usable frames = entries of type USABLE only.
   Bootloader-reclaimable stays reserved for now (Limine structures and the boot stack live there;
   reclaim is a later task; leave a `// TODO(M1-T4)`). Place the bitmap in the first USABLE region
   large enough (frames covering the highest usable address), mark the bitmap's own frames used,
   and mark frame 0 used (never hand out physical page 0). Global instance behind a
   `spin::Mutex`. API: `alloc_frame() -> Option<PhysAddr>`, `alloc_frame_zeroed()`,
   `alloc_contiguous(n_frames, align_frames) -> Option<PhysAddr>`, `free_frame(PhysAddr)`,
   `free_contiguous(PhysAddr, n)`, `stats() -> PmmStats { total, used, free }` in frames, plus
   `for_each_usable_region` if handy. Freeing a frame that is not allocated, or a frame outside
   RAM, is a kernel bug: panic with a clear message (debug builds and release alike).
   Boot log: `[pmm] usable: <MiB> MiB in <n> regions; bitmap <KiB> KiB at 0x..; free frames: <n>`.
5. Wire `mm::init(&memmap, hhdm_offset)` into the shared init path after `idt::init()` in both
   binaries; the normal banner gains a line with total/free MiB (also written to the framebuffer).
6. Tests (`#[test_case]`, ≥ 8 new): bitmap over a 64-word array: set/clear/count; find_free_run
   respects alignment and returns None when no run exists; pmm stats total > 0 and free <= total;
   `alloc_frame` returns a 4 KiB-aligned address that is inside a USABLE region and not the bitmap;
   two allocations differ; alloc N=64 then free them all restores `free` exactly;
   `alloc_frame_zeroed` really is zero (read via HHDM); `alloc_contiguous(8, 8)` returns an address
   aligned to 32 KiB whose 8 frames are then all reported used; frame 0 is never returned across
   1000 alloc/free cycles.

## Acceptance (run all; report exit codes)
- `source scripts/env.sh && gmake test` → 0; serial shows the `[pmm] usable:` summary and `[ok] tests passed (N)` with N ≥ 19
- `gmake fault-test`, `gmake df-test`, `gmake bios-test`, `gmake panic-test` → 0 each
- `gmake shot` → 0 and the banner shows the memory line
- `gmake lint` → 0 (clippy with tests, warnings denied); `gmake build` warning-free
- every `unsafe` block has a `// SAFETY:` comment
