# Brief M2-T4 — `otsh` userspace shell, full 8x16 console font, scripted shell test

## Goal
A person at the keyboard gets a real shell: a prompt, line editing, history, and commands that
inspect and control the system. The console gains a proper 8x16 font with lowercase so output reads
normally. A scripted test types into the shell through QEMU and checks the results. Closes M2.

## Applies
D2, D6, D11 (font licence recorded in THIRD_PARTY_NOTICES.md), D16, D17.

## Where things are
Userspace workspace user/ (libotter, init, hello, utest, crash). Syscalls: kernel/src/syscall/ and
SYSCALLS.md. Console: kernel/src/console/ (currently an original uppercase-only 8x8 font in
kernel/src/font8x8.rs rendered at 2x). QEMU key injection: scripts/qemu.py `--send-keys` with
comma-separated named keys. New: user/sh (the shell), kernel/src/font8x16.rs or console/font.rs.

## Design
1. Font: an 8x16 bitmap font covering printable ASCII 0x20–0x7E, with a permissive licence
   (e.g. Spleen 8x16, BSD-2-Clause, or Terminus 8x16, OFL-1.1; fetch the source file in a
   `gmake deps` step or embed the converted glyph table once, whichever keeps the repo honest about
   where the data came from). Convert to a `[[u8; 16]; 95]` table with a small Python script in
   scripts/ (committed). Console default becomes 8x16 at scale 1 on screens narrower than 1600 px
   and scale 2 otherwise; keep the 8x8 font only if still referenced. Record the licence.
2. New syscalls (update SYSCALLS.md): `proc_list(buf, cap)` returns entries
   `{pid, ppid, state, name[16], ticks}`; `sysinfo(buf)` returns uptime_ms, total/free frames,
   heap bytes in use, process count; `reboot()` via the ACPI FADT reset register when present,
   else the 8042 pulse (0xFE to port 0x64), else triple fault; `test_exit(code)` only honoured when
   the kernel was booted in a test mode (exits QEMU through isa-debug-exit), `-EPERM` otherwise.
3. `/bin/sh` (otsh): prompt `otter> ` (bold via ANSI), line editor with left/right, Home/End,
   Backspace/Delete, Ctrl-A/E/U/L, Up/Down history (64 entries). The kernel's fd-0 path currently
   delivers characters; extend it to deliver the arrow/home/end/delete keys as ANSI escape
   sequences (ESC [ A, B, C, D, H, F, 3~) so the shell reads a byte stream like a terminal.
   Built-ins: `help`, `echo`, `clear`, `ps`, `mem`, `uptime`, `kill <pid>`, `run <prog> [args]`,
   `exit [code]`, `reboot`, `history`. A bare word runs `/bin/<word>` if it exists, else prints
   `otsh: <word>: command not found`. Show the child's non-zero exit code or kill reason after it
   ends. `init` runs `/bin/sh` in normal mode and restarts it if it exits.
4. Scripted test `gmake shell-test` (add to `gmake check`): boots with cmdline `shelltest`; init
   starts `/bin/sh` with argv `--test`, which prints `[sh] ready` on serial; the harness injects:
   `echo hello otter` Enter, `ps` Enter, `hello x y` Enter, `crash null` Enter, `nosuchcmd` Enter,
   up-arrow Enter (history re-runs `nosuchcmd`), `exit 0` Enter. In `--test` mode the shell calls
   `test_exit(code)` when it exits. `--expect-serial` checks (multiple patterns supported, all must
   match, add this to qemu.py if needed): `hello otter`, a `ps` line containing `init` and `sh`,
   `argv=[x, y]`, `killed`, two `command not found` lines. Everything the shell prints goes to the
   console and serial.
5. `gmake shot` in normal mode now shows the shell prompt with lowercase text rendered in the new
   font; the orchestrator will look at it.

## Acceptance (run all; report exit codes)
- `source scripts/env.sh && gmake check` -> all PASS, including the new shell-test
- `gmake test` still reports both kernel and userspace test counts; test counts do not drop
- `gmake shot` -> screenshot shows the `otter> ` prompt and mixed-case text in the 8x16 font
- THIRD_PARTY_NOTICES.md records the font and its licence; every `unsafe` block has a `// SAFETY:` comment
