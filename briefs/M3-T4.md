# Brief M3-T4 — shell file commands, redirection and pipes, programs from disk, persistence test

## Goal
The shell becomes a usable file-system tool, and data written in OtterOS provably survives a
reboot and is readable by macOS tools. Closes M3.

## Applies
D2, D7, D16, D17.

## Where things are
Shell: user/sh. libotter fs/process API from M3-T3 (File, read_dir, Command with redirection,
pipe). Syscalls: SYSCALLS.md. Harness: scripts/qemu.py (`--send-keys`, `--expect-serial` with
multiple patterns), scripts/mkdisk.py (`--fat32`), scripts/fat_check.sh (fsck.fat + mtools checks).

## Design
1. Built-ins added to otsh: `ls [-l] [path]` (name, size, kind; -l adds mtime), `cat <files>`,
   `cd [dir]`, `pwd`, `mkdir [-p]`, `rm [-r]`, `rmdir`, `mv`, `cp [-r]`, `touch`, `stat`, `df`
   (statfs per mount), `sync`, `write <file> <text...>`, `hexdump <file>` (first 256 bytes),
   `find <dir> [name-substring]`. Glob `*` and `?` in arguments (expanded by the shell, sorted).
2. Syntax: `>` `>>` `<` redirection, `2>` for stderr, `|` pipelines of any length (each stage a
   process connected by pipes; built-ins in a pipeline run as a child `sh -c`), `;` and `&&`,
   double-quoted and single-quoted strings with backslash escapes, `$?` last exit code. A small
   recursive-descent parser with unit tests on the host (the parser module is plain Rust with no OS
   calls, so `cargo test` in a host build of that module works; add `gmake host-tests` that runs
   host unit tests for such pure crates and include it in `gmake check`).
3. Programs from disk: a path containing `/` runs that file (e.g. `/data/bin/hello`); `PATH` is
   `/bin:/data/bin`. `cp /bin/hello /data/bin/hello2` then `hello2` runs from the FAT32 volume.
4. Persistence test `gmake persist-test` (in `gmake check`): build a fresh FAT32 image; boot 1 with
   cmdline `shelltest` and injected keys: `mkdir /data/notes`, `write /data/notes/today.txt otters
   hold hands while sleeping`, `cp /bin/hello /data/bin/hello2`, `sync`, `exit 0`. Host step:
   `fsck.fat -n` clean and `mtype ::/notes/today.txt` equals the sentence. Boot 2 on the same image:
   `cat /data/notes/today.txt` and `hello2 persisted`, expect both on serial, `exit 0`.
5. Keep `gmake shell-test` from M2-T4 passing; extend it with a pipeline (`ls /bin | cat`) and a
   redirection round trip (`echo abc > /tmp/x; cat < /tmp/x`).

## Acceptance (run all; report exit codes)
- `source scripts/env.sh && gmake check` -> all PASS, including `host-tests`, `shell-test` and `persist-test`
- test counts do not drop; the host parser tests number >= 15
- every `unsafe` block has a `// SAFETY:` comment
