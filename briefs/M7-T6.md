# Brief M7-T6 — otter-local: Otter's chat engine (ChatML, streaming, sampling, stop, cancel)

## Goal
"Otter chats offline" needs one engine that both the shell's `otter "prompt"` and the desktop's
Otter app drive: build the ChatML prompt, prefill it, then generate token by token in small
steps (so the UI stays responsive), stream valid UTF-8 text, sample with the configured settings,
stop at <|im_end|>, honour max tokens and a Stop button, and report prompt/generation timing.
Pure crate `crates/otter-local` over `otter-llm` (loader, tokenizer, forward pass, ChatML) and
`otter-sample`. Acceptance: `crates/otter-local/tests/oracle.rs` (orchestrator, unchanged; header
= API and semantics), whose reference is transformers' greedy reply to a ChatML prompt.

## Applies
D2, D21, D27 (no_std + alloc, `#![forbid(unsafe_code)]`, path dependencies only). Add
`otter-local` to `crates/Cargo.toml` members (single-line edit) with
`[profile.dev.package.otter-local] opt-level = 3` (the oracle runs SmolLM2 f32). Files under ~600
lines. Never run git checkout/restore/reset/stash/clean. Tests only via
`scripts/verify-crate.sh otter-local` or `scripts/memguard.py`. Do not edit the oracle.

## Design
1. `otter_llm::Model::tokenizer(&self) -> Result<Tokenizer, TokenizationError>`: build the
   tokenizer from the model's own vocab, merges and added tokens exactly as
   crates/otter-llm/tests/tokenizer_golden.rs does (a small addition to otter-llm; all its
   existing tests must still pass).
2. `ChatEngine` holds the model, an `otter_llm` `Session` (KV cache), the tokenizer, a
   `StreamingDecoder`, an `otter_sample::Sampler` seeded from the config, the prompt and generated
   ids, and the pending logits. `start` builds the prompt with `ChatMlBuilder` (system/user/assistant
   messages, ending with the open assistant turn), encodes it and feeds it; `step(budget)` samples
   (temperature 0 = greedy; top-k, top-p, repetition penalty over the reply so far) and feeds up to
   `budget` tokens, returning the newly decoded text.
3. Default config: temperature 0.0, top_k 0, top_p 1.0, repetition_penalty 1.0, seed 0,
   max_new_tokens 256, stop_ids = [the tokenizer's id for "<|im_end|>"].
4. Timing through the injected `Clock`: `prefill_ms` covers `start`'s feeding, `generate_ms` the
   steps.
