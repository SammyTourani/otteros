# Brief M7-T4 — `otter-sample`: seeded token sampling for Otter (pure crate)

## Goal
The last step of each generated token: turn the model's logits into a token id, reproducibly.
Greedy, temperature, top-k, top-p and repetition penalty, with an optional `allowed` predicate
through which otter-grammar's token mask constrains tool calls. Acceptance:
crates/otter-sample/tests/oracle.rs (orchestrator; its header is the specification).

## Applies
D2, D27 (no_std + alloc, zero external dependencies). f32 logits; accumulate in f64 where it
matters for accuracy. The random generator is a small seeded PRNG in the crate (e.g. xoshiro256**
seeded through splitmix64), never a hardware source, so runs are reproducible.

## Acceptance
`scripts/verify-crate.sh otter-sample` → the 5 oracle tests (and any of your own) pass, clippy ok,
no_std ok, external deps 0. Add "otter-sample" to crates/Cargo.toml members.
