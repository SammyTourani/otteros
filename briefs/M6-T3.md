# Brief M6-T3 — XSAVE/XRSTOR: AVX state for user threads

## Goal
Otter's matrix kernels (otter-simd) use AVX2 in userspace, so a user thread's YMM registers must
survive every context switch. Today the kernel saves 512-byte FXSAVE images (x87 + SSE only; the
upper halves of ymm0-15 are lost). Switch to XSAVE with an area sized by CPUID leaf 0xD when the
CPU supports it, keep FXSAVE as the fallback. Acceptance tests (orchestrator, unchanged):
`kernel/src/test_cases/xsave.rs` and `user/utest/src/avx.rs`.

## Applies
CLAUDE.md conventions (`// SAFETY:` on every `unsafe`, zero warnings). The kernel stays soft-float
(D13): it never uses SIMD registers itself. Never run git checkout/restore/reset/stash/clean. Do
not edit the two oracle files.

## Design
1. `arch::x86_64::fpu`: at `init`, if CPUID.1:ECX.XSAVE[26]: set CR4.OSXSAVE (bit 18), then XCR0 =
   x87 | SSE (| AVX if CPUID.1:ECX.AVX[28]) with `xsetbv`; `area_size()` = CPUID.(0DH,0):EBX read
   after XCR0 is set; `Mode::Xsave`. Otherwise `Mode::Fxsave`, 512 bytes. `xcr0()` returns the
   value set (0 under Fxsave). Log `[fpu] xsave: xcr0 0x7, area 832 bytes` or `[fpu] fxsave`.
2. `fpu::SaveArea`: a heap buffer of `area_size()` bytes aligned to 64 (use `alloc::alloc` with a
   `Layout` of that size and align 64; free on drop), with `as_ptr()`, `len()`, and
   `SaveArea::pristine()` = a copy of the image saved once at boot right after init (so a new
   thread starts with default MXCSR/FCW and clean registers; zero XSTATE_BV bits are fine for
   components in their init state). Replace `FxsaveArea` everywhere (sched::thread's user extra
   data, process creation, the switch path).
3. Save/restore: `xsave64 [area]` / `xrstor64 [area]` with EDX:EAX = the XCR0 mask under Xsave
   (`fxsave64`/`fxrstor64` under Fxsave). Keep the existing eager save-on-switch-out /
   restore-on-switch-in structure in `sched::schedule`.
4. userspace: in `user/utest/src/main.rs` add `mod avx;`, dispatch `utest avx-worker <seed>` to
   `avx::worker(seed)` before the normal battery (return its code), and add
   `check("avx-survives-context-switches", avx::test_avx_survives_context_switches(), ...)`.
   Register `mod xsave;` in `kernel/src/test_cases/mod.rs`.

## Acceptance
- `source scripts/env.sh && gmake check` → all targets PASS; serial shows the `[fpu] xsave` line,
  both xsave tests, and `[utest] ok avx-survives-context-switches` (the gate boots `-cpu max`,
  which has AVX under TCG, so the check must run, not skip).
- `gmake lint` clean.
