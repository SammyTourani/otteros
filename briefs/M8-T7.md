# Brief M8-T7 — CMOS real-time clock and the wall clock

## Goal
OtterOS knows the date: TLS certificate validity (M8/M9 agent mode), FAT timestamps (M3) and the
desktop clock need it. Read the CMOS RTC at boot, keep `time::unix_now()` from it plus uptime, log
`[rtc] YYYY-MM-DD HH:MM:SS UTC`. Acceptance tests: `kernel/src/test_cases/rtc.rs` (orchestrator,
unchanged; its header is the API) and the harness check in `scripts/qemu.py`
(`check_rtc_line`, orchestrator, already in place: the logged time must match the host's UTC).

## Applies
CLAUDE.md conventions (`// SAFETY:` on every `unsafe`, zero warnings, `[rtc]` log prefix). Never
run git checkout/restore/reset/stash/clean. Do not edit `kernel/src/test_cases/rtc.rs` or
`check_rtc_line`.

## Design
1. `kernel/src/rtc.rs`: the pure part (`RawCmos`, `DateTime`, `decode`, `to_unix`, `from_unix`,
   days-from-civil arithmetic, no floating point) and the hardware part (`read`): CMOS index port
   0x70 (keep bit 7 set to leave NMI masked as the index is written), data port 0x71; registers
   0x00 s, 0x02 min, 0x04 h, 0x07 day, 0x08 month, 0x09 year, 0x0A status A (bit 7 = update in
   progress), 0x0B status B (bit 2 = binary, bit 1 = 24-hour; in 12-hour mode bit 7 of the hour
   is PM), the century register at the index the FADT gives (FADT byte 108, `CENTURY`; 0 means
   none). A consistent snapshot: wait for UIP clear, read all registers, repeat until two
   consecutive reads agree (bounded: give up with `None` after 1,000 attempts). Serialise access
   with a lock (IRQs disabled while the index/data pair is used).
2. ACPI: expose the FADT century index (`acpi::fadt_century_index() -> Option<u8>`, None when the
   FADT is too short or the byte is 0).
3. `time::unix_now() -> Option<u64>`: the boot-time RTC reading (seconds) plus whole seconds of
   uptime since that reading; None if the RTC could not be read. Boot calls `rtc::init()` after
   ACPI and the timer, logging `[rtc] 2026-09-25 21:40:07 UTC` (zero-padded) or
   `[rtc] unreadable`.
4. Register `mod rtc;` in `kernel/src/test_cases/mod.rs`. In the GNUmakefile, add
   `--expect-serial '\[rtc\] 20[0-9][0-9]-'` to the `test` and `bios-test` commands.
