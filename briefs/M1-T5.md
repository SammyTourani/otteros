# Brief M1-T5 — ACPI tables, local APIC, I/O APIC, 1 kHz timer, interrupts on

## Goal
The kernel discovers the machine from ACPI, programs the local APIC and I/O APIC itself, runs a
1 kHz timer interrupt, keeps time, and turns interrupts on for good, with every shared lock made
IRQ-safe first.

## Applies
D2 (no `acpi` crate; parse the tables yourself), D3 (RSDP comes from the Limine RSDP request),
D5, D13, D14, D15 (MMIO is reached through the HHDM, which covers the first 4 GiB).

## Where things are
Traps: kernel/src/arch/x86_64/{idt,interrupts,trap}.rs (vectors ≥ 32 currently log and return).
Memory: kernel/src/mm/. `without_interrupts` exists in kernel/src/arch/x86_64/interrupts.rs.
New code: kernel/src/acpi/{mod,rsdp,sdt,madt,hpet}.rs, kernel/src/arch/x86_64/{lapic,ioapic,pic,pit,irq}.rs,
kernel/src/time.rs, kernel/src/sync.rs (IRQ-safe mutex).

## Design
1. `sync::IrqMutex<T>`: `spin::Mutex` plus a guard that saves RFLAGS.IF, does `cli` before
   locking and restores IF on drop. Convert SERIAL1, the PMM lock and the heap lock to it.
   (The emergency serial writer stays lock-free.) Test: nested guards restore IF correctly.
2. ACPI: take the RSDP physical address from Limine; validate the RSDP checksum (20 bytes for
   revision 0, 36 for ≥ 2); prefer XSDT, fall back to RSDT; iterate SDT headers, validate each
   checksum, log `[acpi] <SIG> len=<n> rev=<r>`; keep a small `Vec<&'static SdtHeader>` (heap is
   available). Parse MADT (`APIC`): LAPIC base (+ type 5 override), processor LAPIC entries (count
   enabled CPUs, record APIC IDs), I/O APIC entries (address, GSI base), interrupt source overrides
   (ISA IRQ → GSI, polarity/trigger flags), LAPIC NMI entries. Parse `HPET` (base address) if
   present; parse `FACP` just enough to log its revision (used later for power-off). Store the
   summary in a global `AcpiInfo`. Log `[acpi] MADT: <n> cpus, ioapic at 0x.., <k> overrides`.
3. Legacy PIC: remap master/slave to vectors 32–47 and mask everything (all 0xFF), so a stray
   legacy IRQ can never land on an exception vector.
4. LAPIC (xAPIC MMIO through the HHDM; x2APIC support is a later task): enable via the spurious
   interrupt vector register (vector 0xFF, APIC enable bit), TPR = 0, `id()`, `eoi()`. Register a
   spurious handler that only counts.
5. Timer: calibrate the LAPIC timer against the PIT (channel 2, one-shot, 10 ms) — measure LAPIC
   ticks with divider 16 — then program periodic mode on vector 32 at 1000 Hz. `time::ticks()`,
   `time::uptime_ms()`, `time::sleep_ms(ms)` (busy-wait on ticks with `hlt` between checks once
   interrupts are enabled). Log `[timer] lapic timer calibrated: <ticks>/10ms, periodic 1000 Hz`.
6. I/O APIC: read version/max redirection entries, `set_redirect(gsi, vector, apic_id, polarity,
   trigger, masked)`, mask all entries at init, apply MADT overrides when translating ISA IRQ →
   GSI (`irq::isa_to_gsi(irq)`). Keyboard wiring is the next task; only the API is needed now.
7. `irq`: a table of 224 handler slots for vectors 32–255 (`register(vector, fn(&mut TrapFrame))`,
   `unregister`); trap_dispatch calls the handler for vectors ≥ 32 then sends EOI; unregistered
   vectors count as spurious and still EOI. Finally `sti` at the end of init (both binaries), log
   `[irq] interrupts enabled`, and make the idle loop `hlt`.
8. Tests (`#[test_case]`, ≥ 10 new): RSDP checksum valid; at least one SDT with valid checksum;
   MADT present with ≥ 1 enabled CPU and ≥ 1 I/O APIC; LAPIC id equals one of the MADT APIC IDs;
   PIC masks read back 0xFF/0xFF; RFLAGS.IF set after init; ticks advance by ≥ 5 within a 50 ms
   PIT-timed window; `sleep_ms(20)` advances ticks by 18..=30; timer frequency within 20 % of
   1000 Hz measured against the PIT; IrqMutex nested guards restore IF; a registered test IRQ
   handler fires when its vector is raised with `int <vector>`; unregistered vector is counted as
   spurious and execution continues.
