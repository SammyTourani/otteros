# Brief M2-T3 — ELF loader, initramfs, userspace runtime (`libotter`), `/bin/init`

## Goal
Real programs written in Rust under `user/` run as processes. The kernel loads static ELF64 binaries
from a ustar initramfs passed as a Limine module, starts `/bin/init` as pid 1, and `spawn`/`wait`
work from userspace. Userspace may use SSE (the kernel saves user FPU state per thread since M2-T2).

## Applies
D2, D6, D13, D16 (ABI), D17 (process model, `spawn` not `fork`), D18 (static non-PIE ELF at
0x400000; 16 MiB stack below 0x7fff_ffff_f000 with a guard page; argv/auxv SysV-style).
STATUS.md notes: never declare a second static of an existing Limine request type; the module
request is a new type, so one static is fine.

## Where things are
Processes and syscalls: kernel/src/proc/, kernel/src/syscall/ and SYSCALLS.md (from M2-T2).
Scheduler: kernel/src/sched/. New kernel code: kernel/src/proc/elf.rs, kernel/src/fs/initramfs.rs
(ustar), kernel/src/proc/exec.rs (address space + initial stack). New userspace: a separate cargo
workspace `user/` with crates `libotter`, `init`, `hello`, `utest`, `crash`.

## Design
1. Userspace target: a custom target spec `user/x86_64-otter.json` derived from
   x86_64-unknown-none but with SSE/SSE2 enabled and hard-float (no soft-float), static relocation
   model, `panic-strategy: abort`, linker = rust-lld with `user/link.ld` (text at 0x400000, W^X
   segments, page-aligned). Build with `-Zbuild-std=core,alloc,compiler_builtins` and
   `compiler-builtins-mem`, release profile, `opt-level = 2`, stripped. `user/.cargo/config.toml`
   carries this so the kernel's root config never applies (check how cargo resolves config from the
   invocation directory; build user crates with `cd user`).
2. ELF loader (`elf.rs`): validate magic, class 64, little endian, version, EM_X86_64, ET_EXEC; walk
   program headers with bounds checks against the file length; for each PT_LOAD: vaddr within
   [0x400000, 0x0000_7000_0000_0000), `p_filesz <= p_memsz`, no overlap with the stack region or
   with another segment, W and X never both set (reject); allocate zeroed frames, copy file bytes,
   leave the bss zero, map USER + (WRITABLE if W) + (NX unless X). Ignore PT_GNU_STACK, reject
   PT_INTERP and PT_DYNAMIC (static only), reject PT_TLS for now with a clear error. Entry must lie
   in an executable segment. Errors are values (`ElfError`), never panics.
3. initramfs (`initramfs.rs`): ustar parser over the Limine module named `initramfs` (module
   request, one static): validate header checksums, handle the `prefix` field, regular files and
   directories only; `open(path) -> Option<&'static [u8]>`, `list() -> impl Iterator`. Log
   `[initramfs] <n> files, <KiB> KiB`.
4. `spawn(path, argv)` syscall (was -ENOSYS): copy the path and argv from user memory with the
   M2-T2 `usermem` helpers (limits: path 256 bytes, 32 args, 4 KiB total), look the file up, create
   the process, build the initial stack at the top of the user stack region: argc, argv pointers,
   NULL, envp NULL, auxv (AT_PAGESZ 4096, AT_ENTRY, AT_RANDOM -> 16 bytes from the TSC for now,
   AT_NULL), strings above; rsp 16-byte aligned pointing at argc. Returns the pid or a negative
   errno (ENOENT, ENOEXEC for bad ELF, E2BIG, EFAULT). `wait(pid)` returns the exit code (ECHILD
   if not a child). Update SYSCALLS.md and the errno list.
5. `libotter`: `_start` (naked) reads argc/argv from the stack, aligns, calls
   `main(args: &[&str]) -> i32`, then `exit`; syscall wrappers for everything in SYSCALLS.md;
   a global allocator backed by `map_anon` (size-class free lists for small objects, direct
   `map_anon` for >= 64 KiB, freeing back with `unmap`); `print!`/`println!`/`eprintln!` on fd 1/2;
   `read_line` on fd 0; `args()`, `spawn(path, &[args]) -> Result<Pid, Errno>`, `wait(pid)`,
   `sleep_ms`, `time_ms`, `getpid`; a panic handler that prints `panic in <prog>: <msg>` to fd 2 and
   exits with 101. No std; `alloc` is fine.
6. Programs: `init` prints `[init] OtterOS userspace up (pid 1)`, spawns `/bin/hello a b` and waits,
   prints the exit code; in normal mode it then spawns `/bin/sh` if present (next task) or idles
   with `sleep_ms` in a loop; with argv `test` it runs `/bin/utest` and exits with its code.
   `hello` prints `hello from /bin/hello argv=[a, b]` and exits 0. `crash <kind>` performs a null
   read, a divide by zero, or an invalid opcode. `utest` runs >= 10 checks and prints one
   `[utest] ok <name>` or `[utest] FAIL <name>: <why>` line each, then `[utest] passed N/M`:
   allocator stress (Vec of 100 000 u64, BTreeMap of 10 000), strings/format, args round trip,
   spawn + wait of hello (exit 0), spawn of a missing path gives ENOENT, spawn of a non-ELF file
   gives ENOEXEC, `crash null` is killed and wait reports the kill code while utest survives,
   `crash div0` likewise, sleep_ms(50) advances time_ms by 30..=500, map_anon/unmap round trip,
   SSE float math (sum of 1000 f64 sqrt values within 1e-9 of the expected value).
7. Build and boot wiring: the GNUmakefile builds `user/` and packs `build/initramfs.tar` with Python
   `tarfile` (USTAR format, `bin/init`, `bin/hello`, `bin/utest`, `bin/crash`), adds it to every ISO
   variant as a Limine module (`module_path: boot():/boot/initramfs.tar`,
   `module_cmdline: initramfs`). Normal boot: after scheduler init the kernel spawns `/bin/init` as
   pid 1; if init exits the kernel logs `[proc] init exited with <code>` and keeps running the idle
   thread. Test boot: after the in-kernel tests pass, the kernel spawns `/bin/init test` and waits;
   the final QEMU exit status is the AND of both, with serial lines `[ok] tests passed (N)` and
   `[ok] userspace tests passed (N)`. The M2-T1 kernel echo thread only runs when no initramfs is
   present.
8. Kernel tests (`#[test_case]`, >= 8 new): ELF rejects bad magic, 32-bit class, wrong machine,
   truncated program headers, a segment outside the user range, a W+X segment, filesz > memsz;
   ELF accepts the real `hello`; ustar checksum failure rejected; ustar prefix field joined;
   initial stack layout of a spawned process (read back argc/argv/auxv through its address space).

## Acceptance (run all; report exit codes)
- `source scripts/env.sh && gmake check` -> all PASS
- `gmake test` serial shows `[ok] tests passed (N)` and `[ok] userspace tests passed (M)` with M >= 10, and a `[proc] pid .. killed` line from the crash checks
- `gmake shot` shows the `[init] OtterOS userspace up (pid 1)` line on the console
- SYSCALLS.md matches the kernel table; every `unsafe` block has a `// SAFETY:` comment
