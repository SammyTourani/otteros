# Brief M8-T3 — `otter-crypto` part 3: big integers, RSA and ECDSA signature verification

## Goal
Verify the signatures that TLS 1.3 certificate chains and CertificateVerify messages carry: RSA
PKCS#1 v1.5 and RSA-PSS (2048–4096-bit moduli) and ECDSA over P-256 and P-384. A TLS client only
verifies, so every operation here works on public data; strict parsing and exact correctness
matter most.

## Applies
D2, D22, D27.

## Scope and boundaries (other agents work in kernel/ and user/ concurrently)
Touch only `crates/otter-crypto/`, `scripts/gen-crypto-vectors.py` (extend it) and the
THIRD_PARTY_NOTICES.md Wycheproof section. Do not run gmake or QEMU.

## Design
1. Big integers: fixed-capacity u64 limbs sized for 4096-bit moduli plus margin, big-endian byte
   conversion with strict length checks, comparison, Montgomery multiplication and reduction,
   modular exponentiation (square-and-multiply; public exponents such as 65537).
2. RSA verification: RSASSA-PKCS1-v1_5 for SHA-256/384/512 (build the expected encoded message with
   the DigestInfo prefix and compare it in full; never parse padding loosely) and RSASSA-PSS with
   MGF1 (salt length equal to the hash length, as TLS 1.3 requires; all RFC 8017 §9.1.2 checks).
   Public keys: modulus 2048–4096 bits, odd exponent >= 3.
3. P-256 and P-384: field arithmetic modulo p, Jacobian or projective coordinates with the
   complete addition formulas of Renes–Costello–Batina (no special cases to get wrong), SEC1
   uncompressed point decoding with an on-curve check, rejection of the point at infinity. ECDSA
   verification per FIPS 186-5: r and s in [1, n-1], strict DER signature parsing (minimal INTEGER
   encodings, no trailing bytes), hash truncated to the order's bit length, u1·G + u2·Q via
   Shamir's trick.
4. API: `rsa::PublicKey::from_components(n, e)`, `verify_pkcs1v15(alg, digest, sig)`,
   `verify_pss(alg, digest, sig)`, `p256::PublicKey::from_sec1(bytes)`, `verify(digest, der_sig)`,
   the same for p384; errors are values, never panics.

## Tests (host)
Differential big-integer tests against Python integers (the script emits random 2048- and 4096-bit
cases for multiplication, reduction and exponentiation); Wycheproof ecdsa_secp256r1_sha256_test,
ecdsa_secp384r1_sha384_test, rsa_signature_2048_sha256_test (and the 3072/4096 variants present in
the repository), rsa_pss_2048_sha256_mgf1_32_test and rsa_pss_4096_sha512_mgf1_64_test: every
valid case verifies and every invalid case is rejected. Also run the suite for
`--target x86_64-apple-darwin` under Rosetta.
