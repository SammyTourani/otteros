# Brief M10-T0a — otter-usb part 1: descriptors, control requests, HID boot devices, mass storage

## Goal
The laptop demo boots from a USB stick and keeps its data partition on it, and USB keyboards and
mice must work: the kernel's xHCI driver (M10-T1) needs the protocol logic above the host
controller. Build it as a pure crate, fully host-tested: `crates/otter-usb`, passing
`crates/otter-usb/tests/oracle.rs` (orchestrator, unchanged; its header is the exact API and the
semantics the specifications leave open).

## Applies
D2, D27: `#![no_std]` + `alloc`, zero dependencies, `#![forbid(unsafe_code)]`. Add `otter-usb` to
`crates/Cargo.toml` members. Files under ~600 lines: `src/lib.rs` (modules only), `src/desc.rs`,
`src/setup.rs`, `src/hid.rs`, `src/msc.rs`. Never run git checkout/restore/reset/stash/clean. Run
tests only through `scripts/verify-crate.sh` or `scripts/memguard.py`. Do not edit the oracle.

## Design
1. `desc`: bounds-checked parsers for device, configuration (walking every descriptor inside
   wTotalLength), string (UTF-16LE with U+FFFD for unpaired surrogates) and language-list
   descriptors. Public types derive Debug, Clone, PartialEq, Eq (Copy for the small ones).
   Field types: u16 for versions/ids/lengths/max_packet_size, u8 for the rest; `hid_report_length:
   Option<u16>`; `max_burst: u8` (0 without a SuperSpeed companion); `mult: u8` = wMaxPacketSize
   bits 11-12; `ep0_max_packet()` = 1 << bMaxPacketSize0 when bcdUSB >= 0x0300, else the byte.
2. `setup`: `SetupPacket` (fields request_type: u8, request: u8, value: u16, index: u16, length:
   u16) with the named constructors and little-endian `to_bytes()`.
3. `hid`: `BootKeyboard` keeps the previous accepted report (8 bytes) and translates reports to
   scan code set 1 exactly as the oracle's header says (a `const` table indexed by usage; E0 keys
   carry the prefix); `leds(num, caps, scroll)` is the output-report byte (bit 0 Num, 1 Caps, 2
   Scroll); `MouseReport { buttons: u8, dx: i16, dy: i16, wheel: i8 }`.
4. `msc`: `Cbw { tag: u32, data_length: u32, direction_in: bool, lun: u8, cb: [u8; 16], cb_len: u8 }`
   with `to_bytes()` ('USBC' little-endian signature, flags 0x80 for IN); the SCSI command
   builders; `parse_csw` with the BOT 6.3 validity/meaning checks in the order length, signature,
   tag, status, residue; READ CAPACITY(10/16), sense (fixed 0x70/0x71 and descriptor 0x72/0x73
   formats) and INQUIRY parsers.
