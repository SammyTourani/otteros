# Brief M6-T1 — application processors online (Limine MP), per-CPU state, cross-calls

## Goal
Otter's inference needs every core. Bring all CPUs online and give each its own GDT/TSS (own RSP0
and IST stacks), per-CPU area (GS base), LAPIC and LAPIC timer; APs idle in `hlt` and service a
cross-call primitive (`run_on`) that later work builds TLB shootdowns and reschedule IPIs on.
Threads still run only on the BSP (the SMP scheduler is M6-T2). Acceptance tests:
`kernel/src/test_cases/smp.rs` (orchestrator, unchanged; its header is the API) with the whole
existing suite still passing under `-smp 4`.

## Applies
D25 (Limine MP request; xAPIC and x2APIC), D4, CLAUDE.md conventions (`// SAFETY:` everywhere,
`[smp]` log prefix). Never run git checkout/restore/reset/stash/clean. Do not edit the oracle.

## Design
1. `limine::request::MpRequest` (limine 0.6), with the x2APIC flag when CPUID reports x2APIC. For
   each AP: allocate its kernel stack (guarded, like thread stacks), IST stacks, a GDT+TSS copy, a
   `PerCpu` (index, LAPIC ID, current thread, tick counter, cross-call mailbox) and write the
   `goto_address`; the AP entry loads its GDT/TSS, the shared IDT, its GS base, enables its LAPIC
   (xAPIC MMIO or x2APIC MSRs, whichever the BSP uses), starts its LAPIC timer with the BSP's
   calibration, sets `online`, enables interrupts and idles in `hlt`. BSP waits (bounded, 1 s per
   AP) and logs `[smp] 4 CPUs online (x2apic|xapic)`.
2. `percpu`: replace the single static `PERCPU` with per-CPU areas reached through GS
   (`current_cpu()` reads the index from GS-relative memory); keep the existing swapgs/syscall
   paths working on every CPU (DF/NMI handlers included).
3. IPIs: `lapic::send_ipi(dest_lapic_id, vector)` for xAPIC (ICR high/low, wait for delivery
   status) and x2APIC (ICR MSR). Cross-call: a per-target mailbox (function, argument, result,
   sequence number) protected by a lock; `run_on` fills it, sends a dedicated vector, and spins
   (with a 1 s timeout that panics with a clear message) until the target writes the result and
   bumps the sequence; the handler runs `f(arg)` with interrupts disabled and sends EOI.
4. Timers: each CPU counts its own LAPIC timer interrupts (`ticks_on`); only the BSP's timer drives
   scheduling and `time::uptime_ms` for now.
5. QEMU: `scripts/qemu.py` gains `--smp N` (default 4 for every target) and the gate runs with it;
   `gmake run` too.
6. Audit every existing lock that an AP could now touch (per STATUS: `random.rs`'s IRQ jitter ring
   index must become fetch_add-safe, or APs must not feed it yet); document in the report which
   globals are BSP-only until M6-T2.

## Acceptance
- `source scripts/env.sh && gmake check` → every target PASS with `-smp 4`; serial shows the
  `[smp]` line; the four smp tests pass.
- `gmake lint` clean.
