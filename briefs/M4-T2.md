# Brief M4-T2 — `otter-gfx`: 2D graphics, PNG, TrueType text (pure crate, host-tested)

## Goal
One no_std crate renders everything the desktop needs at the quality bar in docs/DESIGN.md:
premultiplied ARGB surfaces, anti-aliased shapes, soft shadows, dithered gradients, vector paths,
PNG decode/encode, and anti-aliased TrueType text with kerning. It is pure computation, tested on
the Mac with `cargo test`, and linked into userspace later.

## Applies
D2 (no graphics, font, image or compression crates of any kind), D11 (fonts are data), D24,
D27 (pure crate in crates/, zero dependencies, host-tested), docs/DESIGN.md.

## Scope and boundaries (another agent is working in kernel/ and user/ concurrently)
Touch only: `crates/` (new cargo workspace: `crates/Cargo.toml`, `crates/.cargo/config.toml`,
`crates/otter-gfx/`), `scripts/fetch-fonts.sh`, `scripts/gen-gfx-fixtures.py`, an appended section
in THIRD_PARTY_NOTICES.md, and appended lines in .gitignore. Do NOT edit kernel/, user/,
GNUmakefile, scripts/qemu.py, scripts/check.sh or any *.md other than THIRD_PARTY_NOTICES.md and
the crate's own README. Do not run gmake or QEMU. The repo-root `.cargo/config.toml` targets the
kernel: make `cd crates && cargo test` run on the host (aarch64-apple-darwin) regardless.

## Design
1. `Surface { w, h, stride, px: Vec<u32> }` premultiplied ARGB8888; `Color` straight RGBA with
   `premul()`; exact src-over blending in integer math (`div255` with correct rounding); a clip
   rectangle stack; `sub_surface` views.
2. Shapes: fill_rect, fill_rounded_rect and stroke_rounded_rect with analytic anti-aliased corners,
   fill_circle, anti-aliased lines, linear and radial gradients with 4x4 ordered dithering (no
   visible banding on the DESIGN.md wallpaper), box shadows for rounded rectangles (offset, blur
   radius, spread, colour) via a separable blur of an alpha mask, cached by size; blit with alpha,
   bilinear scaled blit.
3. Paths: move/line/quad/cubic/close, adaptive flattening, non-zero winding scanline rasterizer
   using signed-area accumulation (8-bit coverage), transform (affine). Shared by glyphs, icons and
   the boot-splash otter mark.
4. Compression and PNG: zlib inflate (stored, fixed and dynamic Huffman blocks, Adler-32 verified),
   PNG decode (CRC-32 verified; colour types 0, 2, 3, 4, 6; bit depths 1–8 and 16 downsampled; all
   five filters; tRNS; Adam7 interlace supported or rejected with a clear error), PNG encode (zlib
   with fixed-Huffman or stored blocks) for screenshots.
5. TrueType (glyf outlines only; reject CFF with an error): table directory, head, maxp, cmap
   formats 4 and 12, hhea/hmtx, loca/glyf with simple and composite glyphs (transforms, recursion
   limit), implied on-curve points, kerning from `kern` format 0 and GPOS pair adjustment (lookup
   type 2, formats 1 and 2, for the default script/language). Every table read is bounds-checked;
   malformed fonts return errors, never panic.
6. Text: UTF-8 decode, glyph cache keyed by (font id, glyph, pixel size, subpixel x offset in
   thirds), coverage gamma tuned so light-on-dark and dark-on-light text both look even, `measure`,
   `draw_text`, word wrap to a width, ellipsis truncation, tab stops, `.notdef` fallback box.
7. Fonts: `scripts/fetch-fonts.sh` downloads Inter and JetBrains Mono official releases (OFL-1.1),
   extracts static TrueType-outline `.ttf` files (Regular and SemiBold for Inter, Regular and Bold
   for JetBrains Mono) into `third_party/fonts/`, verifies SHA-256 hashes pinned in the script, and
   copies the licence text. THIRD_PARTY_NOTICES.md gets a Fonts section.
8. Fixtures: `scripts/gen-gfx-fixtures.py` (Python stdlib only: zlib, struct) writes zlib streams
   with stored/fixed/dynamic blocks and PNGs covering each colour type, bit depth and filter into
   `crates/otter-gfx/tests/fixtures/` (committed, small), with expected pixel values alongside.

## Tests (host `cargo test`, >= 30)
Blend edge cases; premul round trip; rounded-rect and circle coverage area within 1% of analytic;
symmetry of anti-aliased corners; gradient endpoints exact and dither error bounded; shadow blur
preserves total alpha; inflate for every fixture plus corrupted-stream errors; PNG decode for every
fixture and CRC failure detection; PNG encode/decode round trip; cmap lookups for ASCII and `é`;
JetBrains Mono advances are all equal for ASCII; glyph bboxes inside the head bbox; composite `é`
has two components; a rasterized `l` has the expected stem width at 32 px; `o` has an empty
centre; kerning pair `AV` in Inter is negative; malformed-font fuzz (truncate the font at 200
offsets, flip random bytes) never panics.

## Specimen
A test renders `artifacts/gfx-specimen.png` (via the crate's own PNG encoder): the DESIGN.md
wallpaper gradient, three overlapping rounded windows with shadows and title bars, ASCII in Inter
at 12/14/18/24/48 px and JetBrains Mono at 14 px, light-on-dark and dark-on-light text, a stroked
and filled vector shape. The orchestrator will look at it; make it look like DESIGN.md.
