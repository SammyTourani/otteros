# Brief M2-T2 — ring 3: processes, address spaces, syscall/sysret, user faults

## Goal
The kernel runs code in ring 3 inside its own address space, services system calls through
`syscall`/`sysret`, isolates processes from each other, grows user stacks on demand, and kills a
misbehaving process without harming the kernel. ELF loading comes next; this task uses tiny
hand-assembled user payloads embedded in the kernel to prove the mechanism.

## Applies
D2, D4, D13 (save/restore user FPU state per thread with FXSAVE/FXRSTOR at context switch — the
kernel itself never uses SSE), D14, D15, D16 (ABI: rax number; rdi, rsi, rdx, r10, r8, r9; result
in rax, negative errno), D17, D18 (user layout).

## Where things are
Scheduler: kernel/src/sched/. Address spaces: kernel/src/mm/vmm.rs (`AddressSpace::new_user`
shares the kernel half). GDT selectors: kernel 0x08/0x10, user data 0x18, user code 0x20 (see
kernel/src/arch/x86_64/gdt.rs). Trap frames: kernel/src/arch/x86_64/trap.rs. New code:
kernel/src/proc/{mod,process,fault,usermem}.rs, kernel/src/arch/x86_64/{syscall_entry.rs (asm),
usermode.rs, percpu.rs, fpu.rs}, kernel/src/syscall/{mod,table,errno}.rs, test payloads in
kernel/src/test_cases/payloads.rs (bytes with a commented disassembly) and tests in
kernel/src/test_cases/proc.rs.

## Design
1. Per-CPU area (`percpu.rs`): a struct reachable through `KERNEL_GS_BASE`/`swapgs` holding
   `kernel_rsp` (current thread's kernel stack top), `user_rsp_scratch`, `current_thread`.
   Set `GS_BASE`/`KERNEL_GS_BASE` MSRs at init; keep them consistent on context switch.
2. Syscall MSRs: EFER.SCE; STAR = kernel CS 0x08 in bits 32..47 and 0x10 in bits 48..63 (so
   `sysret` yields CS 0x23 / SS 0x1b); LSTAR = `syscall_entry`; SFMASK clears IF, TF, DF, AC.
3. `syscall_entry` (naked asm): `swapgs`; save user rsp to the per-CPU scratch; load kernel rsp;
   push a `SyscallFrame` (user rsp, rcx=rip, r11=rflags, all argument registers and callee-saved
   registers); `sti`; call `syscall_dispatch(&mut SyscallFrame)`; `cli`; restore; `swapgs`;
   `sysretq`. Stack alignment as in the trap stubs. If the dispatcher marks the thread as
   exiting, never return to user mode: switch away.
4. `Process` (`process.rs`): pid, name, `AddressSpace`, main thread, state, exit code, parent
   pid, `brk`/anonymous-mapping cursor (starts at 0x0000_0000_1000_0000), user stack region
   (reserved 16 MiB below 0x0000_7fff_ffff_f000 with a guard page; only the top 64 KiB mapped at
   start), children/wait queue. Process table: `BTreeMap<Pid, Arc<Process>>` behind an IrqMutex.
5. Entering ring 3 (`usermode.rs`): build an iretq frame (ss 0x1b, rsp, rflags with IF=1 and
   bit 1, cs 0x23, rip) on the thread's kernel stack and `iretq`. Before that: switch CR3 to the
   process address space (do it in the scheduler when the incoming thread's process differs),
   set TSS RSP0 and per-CPU `kernel_rsp`.
6. User memory access (`usermem.rs`): `copy_from_user(dst, user_ptr, len)`,
   `copy_to_user`, `user_str(ptr, max)`; validate that [ptr, ptr+len) lies below
   0x0000_8000_0000_0000 and that every page is mapped with the USER flag (walk with
   `translate`); return `-EFAULT` otherwise. No SMAP yet (note a TODO).
7. Syscall table (`table.rs`, numbers fixed and documented in a `SYSCALLS.md` at the repo root):
   0 exit(code), 1 write(fd, buf, len) [fd 1 and 2 → console + serial], 2 read(fd, buf, len)
   [fd 0 → keyboard chars, blocking], 3 getpid, 4 yield, 5 sleep_ms, 6 map_anon(len) → addr,
   7 unmap(addr, len), 8 time_ms, 9 spawn (returns -ENOSYS until M2-T3), 10 wait(pid) → exit
   code, 11 kill(pid), 12 debug_log(buf, len) → serial only. Unknown → -ENOSYS. Errno set in
   `errno.rs` (EPERM, ENOENT, ESRCH, EFAULT, EINVAL, ENOMEM, ENOSYS, ECHILD, EAGAIN).
8. Faults from ring 3 (`fault.rs`, hooked from the trap dispatcher when `frame.cs & 3 == 3`):
   page fault inside the process's reserved stack region → map a zeroed frame and resume
   (demand growth); any other page fault, #GP, #UD, #DE, #SS, #AC → log
   `[proc] pid <n> (<name>) killed: <exception> at rip=0x.. addr=0x..`, mark exit code
   128+signal-like constant, wake waiters, schedule away. The kernel must keep running. A fault
   in ring 0 keeps the existing panic behaviour.
9. Process teardown: on exit/kill, free user frames (walk the address space's user half: leaf
   frames and intermediate tables), free the kernel stack via the reaper, remove from the table
   after `wait` collects it (zombie until then).
10. FPU: `fxsave`/`fxrstor` areas (512 B, 16-aligned) per thread that has entered ring 3; save
    on switch-out, restore on switch-in. CR0/CR4 bits (MP, NE, OSFXSR, OSXMMEXCPT) set at boot so
    user SSE works.
11. Test payloads (hand-assembled, each ≤ 64 bytes, with commented mnemonics): `hello` (write
    "hi from ring 3\n" to fd 1 via syscall, then exit(7)); `fault` (read from address 0);
    `spin` (infinite loop); `badptr` (write with a kernel-half pointer → expects -EFAULT, returns
    it via exit code); `growstack` (touch rsp - 1 MiB then exit(0)); `nosys` (syscall 999 → exit
    code = -result). Helper `spawn_payload(name, bytes) -> Pid` maps the bytes at 0x400000 as
    RX in a fresh address space.
12. Tests (`#[test_case]`, ≥ 10 new): hello exits with 7 and its text appeared on serial;
    fault payload is killed with a PAGE FAULT log and the test continues; spin payload does not
    starve the kernel (test thread keeps running) and `kill(pid)` ends it; wait returns the exit
    code; two processes writing the same virtual address have different physical frames
    (translate through each address space); badptr gets -EFAULT; nosys gets -ENOSYS; growstack
    succeeds (stack demand-grows); after a process exits, PMM free frames return to baseline
    (no leaks, allow the process-table entry); a syscall from process B after process A ran
    works (per-thread RSP0/kernel_rsp correct).

## Acceptance (run all; report exit codes)
- `source scripts/env.sh && gmake check` → all PASS; `gmake test` reports `[ok] tests passed (N)` with N ≥ 115
- serial shows `hi from ring 3` and a `[proc] pid .. killed: PAGE FAULT` line during the test run
- SYSCALLS.md exists and matches table.rs
- every `unsafe` block has a `// SAFETY:` comment
